# 電卓 (calc7seg) — Android

市販の卓上電卓風、10 桁 7 セグ液晶の軽量電卓。パッケージ `com.zmlworks.calc7seg`。
Plain Java + framework View のみ（ライブラリなし）。

## キー配列（4 列）

```
MC   MR   M-   M+
1/x  Ans. CA   CE
BS   √    +/-  ÷
7    8    9    ×
4    5    6    −
1    2    3    +
0    00   .    =
```

## 液晶

```
 ZML                 ┌──────────────────────┐
 10 DIGITS           │ 8.8.8.8.8.8.8.8.8.0. │ ← メモリ（別枠の小型液晶）
             MEMORY  └──────────────────────┘
┌────────────────────────────────────────────┐
│ [+][−][×][÷]    E                         │ ← 固定位置のアナンシエータ（中抜き）
│ -8.8'8.8.8'8.8.8'8.8.                    │ ← メイン 10 桁（3 桁区切り）
└────────────────────────────────────────────┘
```

- メモリ: メイン液晶とは別のベゼル付き小型液晶。常に点灯表示で、未使用（0）のときは「0.」。メイン液晶の M 表示は廃止
- 演算子: + − × ÷ の 4 つを左上の決まった位置に配置。保留中の 1 つだけが「黒地に白抜き」（セグメント色のブロックから記号を中抜き、液晶地が透ける）で点灯、他は同じブロックの薄いゴースト。演算子を押してから = / CA / E まで点灯
- E インジケータ: 演算子列の右、少し間を空けて配置
- 3 桁区切り: 小数点から左へ 3 桁ごとに「'」を桁間の上部に表示（メイン・メモリ両方。数値には含まない）。区切り位置はすべての桁間にゴーストあり
- 7 セグ書体: 0.2/0.3 の太め・縦長の六角形セグメント。小数点は丸で、桁の下端より少し下に、3 桁区切り「'」は桁の上端より少し上に表示

- 筐体: スーパーファミコン風の淡いウォームグレーの樹脂（上 `#D6D4D0` → 中 `#CECCC7` → 下 `#C3C1BC` の縦グラデーション＋細かいシボ）。キー周りの凹みは一段濃いグレー
- 印字: 「ZML」はチャコール `#34363A`、「10 DIGITS」はアクセントの朱 `#9E3A1A`（CA/CE キーと同系）、「MEMORY」はグレー `#56585D`
- 液晶ベゼル: 黒い窓枠はそのまま、グレーの筐体との境目に成形の縁 `#6A6966`
- キー: 0.6 の色のまま
- ステータスバー / ナビゲーションバー: 筐体色に合わせた明るいバー＋濃いアイコン
- ランチャーアイコン: アダプティブアイコン（ベクター、`tools/icon/make_icon.py` で生成）。アプリの接写風の構図: メイン液晶の右下隅（黒い太いベゼルの丸い角）に大きく点灯した「0.8」、左へ画面外に消えていくゴーストの「8」と「'」、その下に筐体の帯と M+ キーの上部。テーマアイコン用モノクロレイヤー付き

## 操作感

- キー音: 歯切れのよい「カシャッ」系のスナップ音（明るいアタック＋細かいカチャつき＋短い余韻）1 種類のみ（`res/raw/key_snap.wav`、40 ms / 3.5 KB、`tools/sound/make_click.py` で生成）。毎回同じ音・同じピッチで SoundPool 再生。音量は中程度。**メディア音量**に従う（AudioAttributes `USAGE_MEDIA` + `CONTENT_TYPE_SONIFICATION`、アプリ表示中は本体の音量キーもメディア音量を操作）。オーディオフォーカスは取らないので、他アプリの音楽は止まらない
- バイブ: キーを押した瞬間（タッチダウン）に軽い触覚フィードバック
- 設定: 「=」長押しで設定ダイアログ（バイブ / キー音のオン・オフ、初期値は両方オン、SharedPreferences に保存）。長押しでは計算しない
- キー: 実写風のプラスチックキー。画像ファイルは同梱せず、ソフトウェア Canvas で一度だけ描画してビットマップにキャッシュ（色・サイズ・押下状態ごとに共有、ラベルは描画時に重ねる）。ボディの凹み（上側の内影・下縁の照り返し）、ぼかしたアンビエントオクルージョン、側面、上から照らしたキートップ、角の丸みによる光の減衰、浅い凹面、柔らかいスペキュラ、上縁ハイライト、手続き生成の細かいシボ（ノイズ）、パッド印刷風ラベル。押下時はキーが沈み、暗くなり、影が締まる

## 計算仕様（`Calculator.java`、BigDecimal）

- 即時実行の連鎖: `2 + 3 × 4 =` → 20
- 定数計算: `=` を続けて押すと最後の演算を第 2 オペランドで繰り返す（`2+3===` → 5, 8, 11 / `2×3==` → 6, 18）。`5 × =` → 25（二乗）
- 結果は 10 桁に切り捨て、末尾の 0 は除去
- |結果| ≥ 10^10 → E（表示は ×10^-10 の値。実機と同じ）、0 除算・負の √ → E。E 中は CA / CE のみ受付
- 1/x: 表示値（入力中・結果どちらでも）を逆数に。10 桁に切り捨て、1/0 は E。√ と同様に第 2 オペランドにも使える（`5 + 1/x =` → 5.2）
- Ans.: 直近の `=` の結果を呼び出す（MR と同じく新しいオペランドになる）。`=` の連打（定数計算）と、保留中演算を完了させる M+/M- でも更新。連鎖計算の途中結果は入らない。CA では消えない。初期値 0、状態保存に含む
- CA: 全クリア（メモリは保持）、CE: 入力中の数値をクリア、BS: 入力中の最終桁を削除
- M+ / M-: 保留中の演算を完了してから表示値を加減算。値はメモリ液晶に表示
- 状態は回転・アプリ再起動をまたいで保持（SharedPreferences）。壊れた保存データは丸ごと捨てて初期状態から始める。画面は縦固定
- +/-: 数値を打つ前（0 のときや演算キーの直後）に押すと、次に打つ数値が負になる（`[+/-] 5` → -5、`5 + [+/-] 3 =` → 2）

## アプリ 0.9.4 の変更

- ディスプレイを斜め（立ち上げ表示）にした時、下辺とその下のキー等の位置はそのままに、上辺だけをメモリー表示ディスプレイの手前（約 3dp の隙間）まで伸ばす（電卓を下から見上げた時の見え方）。数字は伸びた高さに合わせて縦に伸びる。タップで切り替え時は短いアニメーション。通常表示・他の要素の配置は変更なし

## アプリ 0.9.3 の変更

- 数値を打つ前に +/- を押すと符号が消えていた不具合を修正（`[+/-] 5` が 5 になっていた。`5 + [+/-] 3 =` も 8 ではなく 2 に）
- 保存した状態の復元で、演算子・入力中の数字・数値の範囲・エラー表示を検証するようにし、壊れたデータなら初期状態に戻すように
- キーの描画キャッシュに上限を設け、画面サイズが何度も変わってもメモリが増え続けないように
